# Portfólio profissional — Julli Cumming

Site estático responsivo, pronto para publicação no GitHub Pages.

## Publicar pelo GitHub Pages
1. Entre em https://github.com/Julli-Cumming
2. Crie um repositório público chamado `Julli-Cumming.github.io`.
3. Envie o arquivo `index.html` para a raiz do repositório.
4. Abra **Settings → Pages** e selecione a publicação pela branch `main` e pasta `/ (root)`, caso não seja ativado automaticamente.
5. Aguarde a publicação. O endereço esperado será `https://julli-cumming.github.io/`.

## Personalização antes de publicar
- Confira os links do LinkedIn e GitHub.
- Se desejar, acrescente e-mail profissional e links de projetos públicos.
- Revise os textos para garantir que ferramentas e experiências estejam alinhadas ao que deseja divulgar.

O conteúdo evita citar nomes de clientes, dados internos ou métricas não confirmadas.
